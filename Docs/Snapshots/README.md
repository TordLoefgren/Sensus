# Sensus snapshots

This directory keeps selected milestone images from the Sensus workspace.

The `snapshot.png` file in the repository root always shows the latest workspace
state. Images here are dated archives of meaningful milestones, so the visual
progress of the project remains easy to browse without archiving every small
iteration.

## Archive

- [2026-09-15 — Workspace shell](2026-09-15-workspace-shell.png) — the
  workspace before sensor visualization was added.
- [2026-09-18 — Range visualization](2026-09-18-range-visualization.png) — live
  serial and simulated range inputs rendered through the shared visualization
  path.
